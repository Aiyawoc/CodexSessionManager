# 写入绑定不可变计划和完整后代闭包

归档、恢复、导入、裁剪和清理先持久化不可变计划，并在执行前复核能力指纹、目标状态、内容指纹、有效期和完整后代闭包。上下文裁剪不改写来源任务，而是把经依赖保护的裁剪投影写入新派生任务；内容或 lineage mapping 不完整时不允许创建派生任务。永久删除计划只包含一个根闭包，以避免多根执行中断后出现部分完成。这些约束增加派生、复读和多计划操作成本，但保留来源证据并避免不可逆历史编辑或部分删除。

## 当前可用性补充

本 ADR 保留上述安全原则，但不把派生裁剪视为当前可用能力。根据 [ADR 0009](0009-defer-context-projection-application.md)，当前仅交付上下文审查与投影计划；原任务应用不可用，派生投影须在精确协议画像下完成完整真实 round-trip probe 后才能重新开放。`thread/inject_items` 的方法存在、空响应或目标创建不构成持久化证据。
