# CodexSessionManager v1.0.1 测试版加固候选

状态：**源码候选，尚未发布二进制**。本版本仍定位为 prerelease，不宣称生产可用。

## 加固范围

- 增加 `csm schema audit`：输出版本化、脱敏、带自身 SHA-256 的 App Server schema 审计报告，并分类方法新增、移除、稳定性变化和关键字段变化。
- 把人工批准的协议方法清单集中为协议画像；画像缺失或损坏时写入白名单为空，未知 schema 继续只读。
- 增加 `csm acceptance report`：只记录散列任务 ID、计划/备份/审计哈希和固定阶段结果，且固定 `production_ready: false`。
- 库存先建立摘要与后代图，再只深读目标闭包；CLI 策略归档先用摘要预选候选，GUI 更名、备份、归档和永久删除不再全账号深读。
- GUI 增加“备份并复验”：对所选根任务及其完整派生后代执行 age recipient 加密、全包解密校验和审计登记；归档仍是独立计划与确认步骤。
- CLI、GUI 和 Hook 共用应用工作流 Module，统一 App Server 连接生命周期、计划持久化、按需库存和执行结果。
- 裁剪选择、层级规范化和 Token 估算提取为不依赖 Qt 的纯审查状态 Module。
- CI 增加 Apple Silicon `macos-15` 源码工作流；手动 macOS bundle 工作流只接受当前源码 fresh build。Windows bundle 构建补临时 `%LOCALAPPDATA%`、重复安装、无开发运行时 PATH、中文空格路径和 Hook 安装/卸载流程。

## 自动化证据范围

本版本要求 `scripts/check.sh`、`scripts/test_source_workflow.sh`、fresh macOS `scripts/test_full_workflow.sh` 和 Windows build workflow 分层记录结果。单元测试、假 App Server、offscreen Qt、CI runner、本地 bundle 和临时安装只证明对应层级，不能合并称为真实账号或生产 E2E。

真实账号写入与实体 Cocoa GUI 必须由维护者按 [`macOS Runbook`](../acceptance/macos-real-account-v1.0.1.md) 分阶段执行。Runbook 只允许专用无重要内容任务上的派生、备份、复验与归档派生任务；不执行永久删除、恢复、导入或真实 Hook 安装。

## 仍未关闭的发布门禁

- macOS Developer ID 签名、公证和 staple。
- Windows Authenticode、SmartScreen 信誉和实体窗口输入。
- Intel macOS 独立构建与验收。
- 干净机、真实账号和生产环境验收。

在这些证据完成前，任何产物必须明确标记测试、未签名/未公证，并保留 checksum 与回退路径。
