# CodexSessionManager v1.1.0 首次交付候选

状态：**首次交付候选；2026-09-02 基于源码提交 `edbc2cb` 的本机 bundle 与真实账号只读证据已补录**。本版本可以交给首批用户进行受控测试，但不宣称生产就绪、Developer ID 签名/公证完成或跨平台正式发布。

## 首次交付范围

### 对话清理

- 本地规则建立安全候选池，LLM/Skill/MCP 只能排序和解释候选；
- 候选灌入原项目/任务 GUI，由用户取消或补选；
- 展示项目、后代闭包、最后活动时间、大小、风险、建议理由和备份状态；
- “备份”和“归档/反归档”是两个步骤；先创建并完整复验 age 加密备份，再重新读取状态、契约、建议指纹和后代闭包，最后执行受支持操作；
- 第一版任务管理只提供盘点、备份、批量归档和反归档。永久删除、重命名、restore/import 写入、上下文应用和 MCP 写入均不可用。

### 上下文优化与待处理计划

- LLM 建议绑定当前 turn/item ID 和内容指纹后灌入原时间线；
- 本地硬保护和 `validate_selections` 始终拥有最终否决权；
- 上下文审查与投影计划可保存但不修改 Codex；原任务应用不可用，派生投影当前真实 round-trip 失败并保持上游阻塞；
- Hook 成功保存计划时同步创建 `PendingTrimPlan`；
- 待处理页重新检查计划 SHA、内容指纹、能力指纹、有效期和任务状态，只有 `READY` 才能打开原 GUI；
- 当前不运行 `trim apply`，不把目标创建、`{}` 响应或方法存在标记为投影成功；只有新的完整 probe 通过后才可重新研究 `APPLIED`。

当前能力边界：上下文审查/投影计划可用；应用到原任务不可用；派生投影 `blocked_upstream`；敏感信息确定性 `Replace/Redact/Protect` 是后续优先方向。永久删除当前不提供资格盘点、计划、GUI、CLI、Skill、MCP 或执行器；历史证据仅供追溯。

### 记忆管理 MVP

- 只管理用户明确登记的本地 UTF-8 Markdown/文本文件；
- 拒绝路径逃逸、符号链接和未登记路径；指令文件需要独立开关；
- 按 front matter、标题、列表项、段落、代码块和结构空白分段；
- 支持 `KEEP/DELETE/REPLACE/PROTECT`；
- LLM 建议绑定当前 segment ID 与内容 SHA-256，并受到本地结构保护否决；
- 原 GUI 展示完整 unified diff，用户再次确认后创建私有版本、复核并发漂移、原子替换并重读验证；
- 支持不可变恢复计划、恢复前安全备份和审计。

### MCP 与验收

- 首次交付当前门禁是 Codex Desktop 本机 MCP stdio（`csm mcp stdio`）；它不需要 HTTPS、公网端点或 Bearer token；
- Streamable HTTP（`csm mcp serve`）仅用于可选本机诊断，不是默认首次交付门禁；
- 真实 ChatGPT 与固定 Cloudflare Tunnel 属于可选/历史远程 profile，不是默认首次交付阻塞项；启用该 profile 时才执行其独立认证和联调门禁；
- 只暴露盘点、建议准备、打开审查和状态查询，不暴露 archive/unarchive executor、裁剪应用、记忆写入或永久删除执行器；
- `csm acceptance run` 在隔离目录中执行 MCP 白名单、记忆写入/恢复回环、待处理计划生命周期和原 GUI 记忆模式检查；
- `csm acceptance release` 额外要求 age 和稳定安装包；
- `scripts/accept_first_delivery.sh` 串联完整源码门禁、自动报告和可选 macOS bundle 验收。

## 自动化证据的含义

通过 `scripts/check.sh` 和 `csm acceptance run` 只能证明：

- 当前源码格式、静态类型、单元/集成/offscreen GUI 测试和 Skill 合约通过；
- 隔离临时文件中的记忆修改、恢复、审计和待处理状态机闭环通过；
- MCP 工具面没有越出已审查白名单。

版本无关、契约敏感的现行边界：版本、二进制和全量 schema 散列只作为诊断与计划失效证据；归档与反归档由静态、人工复核的五项最小操作契约逐项评估。无关变化自动兼容，相关方法、字段或关键枚举不兼容时只关闭受影响操作。

它们不能替代：

- （启用可选远程 profile 时）真实 ChatGPT 自定义 MCP app 与固定 Tunnel 联调；
- 真实 Codex 账号和实体 Cocoa 窗口输入；
- Apple Developer ID 签名、公证和 staple；
- Windows x64 实体环境、AuthentiCode 和 SmartScreen；
- 公开发布或生产环境验收。
