# 安全不变量

当前边界是版本无关、契约敏感。当前 Codex 版本、二进制散列和全量 schema 散列是诊断与计划失效证据，不是归档授权条件。归档与反归档由静态、人工复核的最小操作契约逐项评估。无关变化自动兼容；相关方法/字段/关键枚举不兼容时只关闭受影响操作。

## 所有 Codex 写入

- 只使用官方 App Server 或 Codex App 原生任务工具。
- 禁止直接写 JSONL、SQLite、rollout 路径、认证或 Codex 配置。
- 消费已持久化、带 SHA-256 的不可变计划。
- 应用前重读 capability fingerprint、状态、内容/管理 fingerprint 和 spawned descendant closure。
- 任何漂移使计划失效；重新生成，不修补旧计划。
- 写入超时先查询真实后置状态，禁止直接重试。
- 父任务操作必须包含并展示全部 descendants。
- `parent_id` 和 `forked_from_id` 必须同时作为图边；缺父节点、环或根闭包重叠均停止写入。
- `CODEX_HOME` 与 `CSM_CODEX_HOME` 必须指向同一数据根。

## 备份与归档管理

- 自动操作最多归档。
- 归档前要求覆盖受影响快照的已验证加密备份。
- 固定、活动、加载中、映射不完整或状态不明的任务停止对应归档/反归档写入。
- 归档和反归档只处理当前明确选择的根及其完整后代闭包；活跃与已归档内容混合选择时停止。
- GUI 表头全选只作用于当前筛选结果，不把隐藏任务隐式加入计划。

## 备份与密钥

- tar 直接流入 age，只产生加密临时目标；完整复验并锁定密文哈希/大小后，才以不覆盖的原子方式发布。
- manifest 位于流尾；校验时完整解密并计算每个成员 checksum，不落地明文容器。
- manifest 的 source fingerprints 必须与逻辑任务条目一一对应；从条目内嵌 `ThreadSnapshot` 重新计算 `backup_fingerprint`，禁止信任包内自报值。
- 备份覆盖证据必须绑定到审计哈希链事件；归档前必须复核当前指纹对应的备份仍然存在且密文哈希、大小未漂移。
- 恢复先完整校验，再第二遍解密导入；第二遍缺少任一已验证成员即失败。
- 口令只由 age 从控制终端读取；不进入模型、CLI 参数、环境、剪贴板建议或日志。
- GUI 只用 CSM 私有数据目录中的一个本机托管 recipient-key：首次用官方 `age-keygen` 生成，以后校验并复用；不写入备份或日志，不在缺失、损坏或权限异常时静默替换。
- 只收集已知 App 管理附件目录；拒绝符号链接和路径逃逸。
- 排除项目源码、Codex 认证和配置。

## 上下文投影与导入

- 上下文审查与投影计划只保存 CSM 计划，不修改 Codex；原任务应用当前不可用。
- 派生投影当前真实 round-trip 未通过；在新的完整协议契约通过持久化、重启、后续模型可见和 reconcile probe 前，不得启用执行器。
- `thread/inject_items` 方法存在、返回 `{}` 或目标 ID 已创建，都不等于投影写入成功。
- 原任务始终保留；未来执行目标若重新开放，也必须保持来源任务不变。
- 任务内容、lineage mapping 或顶层协议字段不完整时拒绝投影计划或写入。
- 当前请求、进行中 turn、目标、审批、未解决错误和未知 item 为硬保护。
- 系统/开发者指令不作为普通历史注入；派生任务重新加载当前项目指令。
- 工具 sidecar 只读、惰性、不可执行。
- 任何未来注入都必须在写后重读派生任务并核验来源 manifest；不自动发起 turn。

## 当前 Codex 写入边界

- 当前 Codex 任务写入仅为 `thread/archive` 和 `thread/unarchive`，均须命中对应最小契约并经过计划、确认、备份、闭包复核和写后重读。
- 永久删除、重命名、restore/import 写入和上下文应用不可用；上游 schema 存在删除、改名或其它写方法不构成 CSM 能力授权。
- MCP 只读、建议和打开审查 GUI，不提供 archive/unarchive executor，也不提供其它 Codex 写入器。
